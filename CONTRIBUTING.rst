======================
为 Django 做贡献
======================

作为一个开源项目,Django 欢迎各种形式的贡献。

贡献形式举例:

* 代码补丁
* 文档改进
* Bug 报告与补丁评审

详尽的贡献指南位于仓库的 ``docs/internals/contributing/`` 目录,也可在线阅读:

https://docs.djangoproject.com/en/dev/internals/contributing/

**警告:没有对应 Trac 工单的非平凡 pull request(除修复错别字以外的任何改动)都会被关闭!** 请先 `提交一个工单`__ 提出你的修改建议。

__ https://code.djangoproject.com/newticket

Django 使用 Trac 跟踪 bug、功能请求及相关补丁,因为 GitHub 没有为社区提供足够好用的工具。补丁可以通过 pull request 提交,但如果不提交工单,你的贡献很可能会无人问津。

行为准则
===============

作为贡献者,你可以帮助我们保持 Django 社区的开放与包容。请阅读并遵守我们的`行为准则 <https://www.djangoproject.com/conduct/>`_。
