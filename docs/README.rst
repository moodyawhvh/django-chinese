文档使用 `ReST`_(reStructuredText)格式和 `Sphinx`_ 文档系统编写,因此可以构建成其他形式,便于查看和浏览。

要生成 HTML 版本的文档:

* 安装 Sphinx(使用 ``python -m pip install Sphinx`` 或其他方式)。

* 在本 docs/ 目录下,在 shell 提示符输入 ``make html``(Windows 上为
  ``make.bat html``)。

随后即可在网页浏览器中查看 ``_build/html/index.html`` 里的文档。
